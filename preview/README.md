# Preview images

Eight images for the project page gallery, 1500 x 1000, in upload order. Built by `tools/build_preview.py`: the figures are read from the results files and the captures are taken from the live page. Paste each caption into the gallery's caption field.

1. `01-cover.png`

   22 of the 27 things I lost in a flood were already in photos I had taken. Already Owned is a Skill for UGREEN AI NAS that finds them and writes the insurer's contents list.

2. `02-baseline.png`

   Measured on my real June 2026 claim: searching the library by file name and date finds 0 of 27 items, while 22 appear in photos taken before the flood (counted by hand).

3. `03-voice-note.png`

   Walk the damaged room with a voice note. The NAS transcribes it and looks for each thing you named in photos captured before the loss. (Practice run on a made-up library.)

4. `04-what-you-forgot.png`

   It then shows belongings that appear in those same photos and that you never named, and reports honestly what it cannot find. (Practice run on a made-up library.)

5. `05-claim-folder.png`

   The result is one claim folder: the contents list with a proof level on every row, plus a copy of each exhibit with its capture time, camera and SHA-256. (Sample from a made-up library.)

6. `06-what-it-refuses.png`

   It documents what exists. It will not alter a receipt, count a photo taken after the loss, guess a value, substitute a similar item, or follow text it reads inside a photo.

7. `07-how-it-is-built.png`

   Five registered NAS experts across seven CLIs, by delegation only. Every write waits for approval, and nothing is deleted, moved or overwritten.

8. `08-rehearsed.png`

   No entrant has hardware in Round 1, so the package was rehearsed on paper against its own 25-case test plan: 22 pass, 3 partial, 0 fail. The count on a real NAS is not measured yet.
