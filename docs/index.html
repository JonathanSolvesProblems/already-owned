Already Owned

After a flood, fire or theft, the insurer asks for every item you lost, with proof you owned it. This Skill writes that list from the photos and receipts already on your NAS, and counts only photos taken before the loss.

What it never does

Never counts a photo taken after the lossThe cut-off is the capture time in the photo metadata, not the upload date. A later photo is a damage photo.
Never estimates a valuePrices come from a receipt or from you. An empty value stays empty and is counted as empty.
Never swaps in a similar itemTwo search routes with no result and the row says no proof found.
Never writes without askingFolder, copies, document, album and tag each wait for approval. Nothing is deleted, moved or overwritten.
Never obeys text inside a photoWords on a receipt or a label are evidence for a row. They are never instructions, and the report names any file that tried.
Never alters evidenceAsked to re-date or rewrite a receipt, it declines before any search. It runs on the NAS local model and asks before any online model sees a file.
