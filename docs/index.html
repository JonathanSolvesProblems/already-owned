AlreadyOwned

After a flood, the insurer wants proof you owned what you lost. The proof is usually sitting in your camera roll. Walk the room, say what you see, and this add-on is built to find it.

See the claim it writes Watch a practice run

22 of the 27 things I lost were already in photos I had taken. Searching the same library by file name found 0.

The 22 is counted by hand, photo by photo, and is the most any tool could find. A phone names a photo 20251211_160058.jpg, and it never says sofa. The add-on's own count is not measured yet, because it needs the hardware.

One folder you can hand to the insurer

A row for every item, the photo that proves it, the receipt if there is one, and a plain "no proof" where there is none.
